搭博客之前我在 Astro 和 VuePress 之间来回摇摆了很久，把结论记下来。

## 两条路的本质区别

| | Astro | VuePress 2 + theme-hope |
| --- | --- | --- |
| 首屏 JS | 默认 0，按需水合 | 有（预渲染 + 水合成 SPA） |
| 功能齐备度 | 需自行组装 | 开箱即用 |
| 配置复杂度 | 配置面小，但要自己写页面 | 选项极多，但配完就完事 |
| 版本状态 | 已发 v7 正式版 | 长期 RC |

<!-- more -->

## 为什么最后选了 VuePress

因为我的目标是**省心**，不是**极致性能**。

Astro 要自己搞定：搜索（Pagefind）、评论组件、标签页、归档页、RSS、深色模式。这些都是 theme-hope 里配一配就有的东西。

对于文字博客，两者首屏差距通常感觉不出来；但在搭建成本上的差距是实打实的。

## 什么时候该选 Astro

- 特别在意国内弱网下的加载数字
- 想要对站点结构有完全掌控
- 需要大量交互组件，不想背 SPA 的运行时开销

## 一个提醒

VuePress 2 长期停留在 RC 状态（现在还是 `2.0.0-rc.31`）。实践上稳定可用、用户量大，但要清楚**你用的是候选版**，将来升级可能遇到破坏性变更。

写完这篇我算是想明白了：**没有最好的工具，只有当前目标下阻力最小的那个。**
